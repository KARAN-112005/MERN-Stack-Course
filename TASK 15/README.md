# Array Operations — JavaScript Assignment

JavaScript functions that receive an array as an argument and perform various operations on it. The page shows only a heading — a dummy array is used for testing, and all results are printed to the **browser console**.

## 📁 Files

| File | Purpose |
|------|---------|
| `index.html` | Just a heading and a note to open the console |
| `style.css`  | Basic styling for the heading |
| `script.js`  | Array functions + dummy array, results logged to console |
| `README.md`  | This file |

## ✅ Functions Implemented

1. **`findMax(arr)`** — *Arrow function*. Finds the maximum number in the array.
2. **`calculateSum(arr)`** — *Anonymous function* assigned to a variable. Calculates the sum of all elements.
3. **`countOdd(arr)`** — *Regular named function*. Counts the number of odd numbers in the array.

As required, each function uses a different function style (arrow, anonymous, regular declaration), and each takes an array as its parameter.

## 🧪 Dummy Test Array

```js
let dummyArray = [4, 8, 2, 11, 6, 7, 10];
```

## ▶️ How to Run

1. Open `index.html` in any browser.
2. Right-click → **Inspect** → go to the **Console** tab to see the results.

# Thala 7 – E-Commerce Website

A responsive **4-page footwear e-commerce website** built with HTML, CSS.

## Pages
- 🏠 Landing Page
- 👟 Product Details
- 🛒 Cart Page
- 💳 Checkout Page

## Features
- Responsive design
- Product gallery
- Add to Cart UI
- Payment methods
- Order summary
- Coupon section
- Modern glassmorphism UI

## Technologies
- HTML5
- CSS3

## Run

Open `index.html` in your browser or use **VS Code Live Server**.

# Task 2

This is a simple webpage ,
It shows one image and one button below it.

## Files in this project

- `index.html` - the structure of the page (the image box and the button)
- `style.css` - all the styling (spacing, colors, sizes)


## How to run this project

1. Put `index.html` and `style.css` in the **same folder**.
2. Double-click `index.html` to open it in your browser (like Chrome).
4. You should see the image with a "Click Me" button below it, centered
   on the page with equal spacing on all sides.

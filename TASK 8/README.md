

## 📋 TASK 8

Develop a **Hamburger Menu** for the mobile view of the Laundry Wallah web app.


## 🗂️ File Structure

```
laundry-wallah-hamburger/
├── index.html    — Page markup with navbar and hero section
├── style.css     — All styling including responsive rules
└── README.md     — This file
```



## 🌐 How to Run

1. Download or clone the project folder.
2. Open `index.html` in any modern browser.
3. Resize the window to **≤ 768px** (or use DevTools mobile view).
4. Click the **☰ hamburger icon** in the top-right corner to open the menu.

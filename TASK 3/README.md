# TASK 3

A beginner-friendly HTML + CSS project that demonstrates the use of various CSS selector types — element, class, and ID selectors — through a visually styled webpage.

---

## Project Structure

```
project/
├── index.html      # Main HTML file
├── styles.css      # External CSS stylesheet
└── README.md       # Project documentation
```

---

## Files Overview

### `index.html`
The main HTML file that links to the external stylesheet and contains all the markup. It demonstrates:
- Headings (`h1`, `h2`, `h4`) styled with classes and IDs
- Paragraphs styled via element, class, and ID selectors
- Anchor (`a`) tags styled purely via element selector (no class or id on the tag)
- Unordered and ordered lists with selectively colored list items

### `styles.css`
The external CSS file linked to `index.html`. 


## How to Run

1. Extract the zip file and save it to your local directory .
2. Make sure `index.html` and `styles.css` are in the **same folder**.
3. Open `index.html` in any web browser.


## Notes

- No inline CSS is used anywhere in this project.
- The `<a>` tag is styled exclusively through the element selector, without any class or id attribute.
- All visual styling is handled entirely through the external `styles.css` file.

# Compound Interest Calculator

## Objective
A JavaScript program that calculates compound interest based on static (predefined) values.

## Files
| File | Purpose |
|---|---|
| `index.html` | Page markup, links `style.css` and `compoundInterest.js` |
| `style.css` | Basic styling for the result card |
| `compoundInterest.js` | Calculates and displays the compound interest |

## How to run
**In the browser (required):**
1. Open `index.html` in any browser.
2. Open DevTools (F12) → Console tab to see the `console.log()` output.
3. The result is also shown on the page itself.


## Output
```
The compound interest after 3 years is: 33100
```

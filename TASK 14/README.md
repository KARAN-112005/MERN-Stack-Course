# Task 14

## Files in this project

- **index.html** – The main webpage. It has a heading and links to the CSS and JS files.
- **style.css** – Makes the page look neat with some basic colors and spacing.
- **script.js** – Contains all the logic for every number operation.
- **README.md** – This file, explaining the project.


## How to run this project

1. Open the folder and double-click `index.html` to open it in your browser.
2. A popup box will appear asking you to type a number — enter any number (try 153!) and click OK.
3. Right-click anywhere on the page and select **Inspect**, then click the **Console** tab.
4. You'll see all the results printed one by one: sum of first n numbers, the multiplication table, whether it's prime, its factors, the digit sum, and whether it's an Armstrong number.

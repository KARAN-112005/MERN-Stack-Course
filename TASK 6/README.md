# Task 6

This is a simple login page I built to practice CSS Flexbox.
The page is split into two halves: an illustration on the left,
and a login form on the right.

## Files in this project

- `index.html` - the structure of the page 
- `style.css` - all the styling 


## How to run this project

1. Put `index.html` and `style.css` in the **same folder**.
2. Double-click `index.html` to open it in your browser (like Chrome).
3. You should see a blue illustration side on the left and a login
   form on the right, filling the whole screen.

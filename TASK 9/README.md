# Laundry Wallah - Task 9

This is the hero section of the Laundry Wallah site, The"Book a service today!" button grows and tilts on hover.

## Files in this project

- `index.html` - the structure (navbar, hero text, CTA button, image)
- `style.css` - all the styling, including the hover animation

## How to run this project

1. Put `index.html` and `style.css` in the **same folder**.
2. Double-click `index.html` to open it in your browser.
3. Hover over the **"Book a service today!"** button to see it grow
   and tilt.
